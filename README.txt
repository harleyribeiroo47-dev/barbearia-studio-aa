BARBEARIA STUDIO A.A — VERSÃO INSTALÁVEL (PWA)

1) Publique esta pasta em um servidor com HTTPS.
2) No iPhone, abra o endereço pelo Safari.
3) Toque em Compartilhar.
4) Toque em "Adicionar à Tela de Início".
5) Toque em Adicionar.

O ícone e a identidade visual já estão incluídos.
Esta versão funciona como aplicativo instalado na tela inicial, sem TestFlight.
Para agendamento real, conecte a API PHP/MySQL do projeto anterior.
